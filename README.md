### **a. ¿Qué es un arquetipo (Archetype) en Maven?**

Un **arquetipo** en Maven es una plantilla o modelo predefinido que permite generar automáticamente la estructura base de un proyecto.  
Funciona como un punto de partida para crear nuevos proyectos con una organización estándar, que incluye directorios, archivos y configuraciones iniciales necesarias. Esto facilita mantener una estructura homogénea en los proyectos dentro de un equipo de desarrollo.

---

### **b. ¿Para qué sirve el arquetipo `maven-archetype-quickstart`?**

El arquetipo **`maven-archetype-quickstart`** sirve para generar rápidamente un proyecto Java básico utilizando Maven.  

Este arquetipo crea automáticamente:

- La estructura estándar de directorios:
  - `src/main/java`
  - `src/test/java`
- Un archivo **`pom.xml`** básico.
- Una clase principal de ejemplo.
- Una clase de prueba unitaria.

Es ideal para iniciar proyectos Java simples, siguiendo las convenciones de Maven.

### **d. ¿Qué es un Pull Request en GitHub?** 

Un Pull Request (PR) en GitHub es una solicitud para revisar y fusionar cambios realizados en una rama hacia otra, generalmente hacia la rama principal (main o master).

Permite que los miembros del equipo revisen el código antes de integrarlo al proyecto principal, garantizando control de versiones, colaboración y calidad del software.

---

### **e. ¿Cómo se crea un Pull Request en GitHub?**

    Para crear un Pull Request en GitHub se deben seguir los siguientes pasos:
    Crear una nueva rama en el repositorio.
    Realizar los cambios necesarios en el código.
    Hacer un commit de los cambios realizados.
    Hacer push de la rama al repositorio remoto.
    Ingresar al repositorio en GitHub.
    Hacer clic en el botón "New Pull Request".
    Seleccionar la rama de origen y la rama de destino.
    Agregar un título y descripción detallada.
    Hacer clic en "Create Pull Request".

---

### **f. ¿Cómo se aprueba un Pull Request en GitHub? **

    El proceso de aprobación de un Pull Request consiste en:
    Un revisor accede al Pull Request.
    Analiza los cambios realizados y puede agregar comentarios o solicitar modificaciones.
    Si todo está correcto, el revisor selecciona la opción "Approve".
    Finalmente, se puede hacer clic en "Merge Pull Request" para fusionar los cambios a la rama principal.
